# Claude Code 用量桌面小工具

把 Claude Code `/usage` 的額度資訊變成常駐桌面的半透明小視窗，
並且在多台電腦共用同一個帳號時，看得出**是誰用掉了額度**。

```
┌────────────────────────────────┐
│ ● Claude Code 用量          ✕  │
│                                │
│ 5 小時區間                 23% │   ← 帳號額度（官方精確數字）
│ ██████░░░░░░░░░░░░░░░░░░░░░░░  │
│ 16:39 重置 · 剩 3 小時 21 分   │
│                                │
│ 每週額度                   13% │
│ ███░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│ 09/03 重置 · 剩 5 天           │
│                                │
│ ── 本 5 小時各 IP 佔用（估算）─│
│ 192.168.1.10（你）        21.7%│   ← 各台的分攤（估算）
│ ████████████████████████░░░░░  │
│ Alice · PC-01 · 13.8M tokens   │
│                                │
│ 小明                       0.9%│
│ █░░░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│ 192.168.1.20 · PC-A · 9.0M     │
│                                │
│ 本機本週 89.5M · 更新 13:50  ↻ │
└────────────────────────────────┘
```

需求：Windows、PowerShell 5.1（系統內建）、已登入的 Claude Code。不必安裝任何額外軟體。

## 快速開始

### 只用一台電腦

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\ClaudeUsageWidget\Install.ps1"
```

這會建立桌面捷徑與開機自動啟動。跑完就會看到小工具出現在螢幕右上角，可以直接拖到你想要的位置。

### 多台電腦一起用

**每一台**都做前三件事，最後一步由管理者做一次：

1. 把整個 `ClaudeUsageWidget` 資料夾複製過去（放哪都可以，建議一樣放在使用者家目錄）
2. 執行上面那行 `Install.ps1`
3. 確認這台的 `T:` 有對應到跟其他台**同一個**網路位置

   程式預設用 `T:\claude_usage`，一般不用改。若你的環境是別的路徑，
   用記事本打開 `ClaudeUsageWidget.ps1` 改開頭那一行：

   ```powershell
   $script:SharedFolder = 'T:\claude_usage'
   ```
4. 由**管理者**到共享資料夾，用記事本編輯 `names.json`，把每台的 IP 與名稱填進去

第 4 步是必要的：`names.json` 同時是白名單，**沒登記的機器不會上傳用量**。
小工具在未登記時會用紅字顯示自己的 IP，把那個 IP 填進對照表即可。
`names.json` 長這樣，沒有的話自己建一個：

```json
{
  "192.168.1.10": "Alice",
  "192.168.1.20": "小明"
}
```

## 深色／淺色主題

兩套色票都取自 Claude 介面的配色：淺色是米白底（`#FAF9F5`）配深墨字，
深色是暖調深灰底（`#262624`）配米白字，強調色都用 Claude 的橘。

右鍵 →「佈景主題」可以選：

| 選項 | 行為 |
| --- | --- |
| **跟隨 Windows**（預設） | 讀 Windows 的淺色／深色設定，你在系統切換後小工具下次更新就跟著換 |
| **淺色** | 固定用淺色，不管系統設定 |
| **深色** | 固定用深色 |

切換是**即時的**，不需要重新啟動。

深色模式下進度條的顏色會刻意調亮——同一組藍／琥珀／紅在深底上會顯得太暗、
彼此難以分辨。兩套都維持「藍（低）→ 琥珀（50% 起）→ 紅（75% 起）」的邏輯，
而且百分比數字本身才是主要資訊，不依賴辨色能力也能判讀。

## 隱藏到狀態列

小工具會在工作列右下角的**通知區域**（時鐘旁邊）放一個圖示，
圖示本身就是一個環形進度，直接畫出目前 5 小時區間的用量——
不用點開視窗、也不用把滑鼠移過去，掃一眼就知道用掉多少。
顏色跟視窗裡的進度條一致：藍（低）→ 琥珀（50% 起）→ 紅（75% 起）。

| 動作 | 做法 |
| --- | --- |
| 收起來 | 點視窗右上角 **✕**，或右鍵 →「隱藏到狀態列」 |
| 叫回來 | **左鍵點一下**狀態列圖示 |
| 看目前用量 | 滑鼠移到圖示上，會顯示「5 小時 23% · 每週 13% · 14:30」 |
| 圖示的右鍵選單 | 顯示／隱藏視窗、立即更新、結束 |
| 真正結束程式 | 右鍵 →「結束」（不是 ✕） |

> **Windows 11 預設會把新圖示收進「^」裡面。** 想讓它固定顯示在工作列上：
> 在工作列空白處按右鍵 →「工作列設定」→「其他系統匣圖示」，
> 把 `PowerShell` 那一項打開。

兩個相關設定（都在右鍵選單裡）：

| 選項 | 說明 |
| --- | --- |
| **按 ✕ 時隱藏而非結束** | 預設開啟。關掉的話 ✕ 就是真的結束程式 |
| **開機時直接縮在狀態列** | 預設關閉。開啟後開機自動啟動時不會跳出視窗擋畫面 |

## 它顯示什麼

畫面分成上下兩段，資料來源與可信度**完全不同**：

### 上半：帳號額度（官方精確數字）

| 項目 | 說明 |
| --- | --- |
| **5 小時區間** | 目前這個 5 小時滾動視窗已用掉的百分比，以及何時重置 |
| **每週額度** | 本週全部模型合計已用掉的百分比，以及何時重置 |
| **每週 Fable 額度** | 特定模型的獨立週額度（沒用到時顯示 0%） |

這幾個數字直接來自 Anthropic，跟你在 Claude Code 裡打 `/usage` 看到的完全一樣。

### 下半：各台佔用（估算）

只有設定了共享資料夾才會出現。每一列的百分比 = 帳號總用量 × 該對象佔全體的比例，
所以**各列加起來會等於上方的帳號總用量**。

灰色那列代表已經一段時間沒有回報（預設超過 20 分鐘），副標會寫「已 N 分鐘未回報」。

## 多台電腦的用量歸因

額度是綁**帳號**的，不是綁機器的。同一個帳號在多台電腦上使用時，
每台打 API 拿到的百分比完全一樣，看不出是哪一台用掉的。
這一節說明小工具怎麼把用量分回各台。

### 怎麼分辨「誰是誰」

主要識別是**固定 IP**，因為 IP 由網管統一配發，比電腦名可靠。
回報檔案就以 IP 命名，一個 IP 一個檔（例如 `192.168.1.20.json`）。

IP **一律自動偵測**，不提供手動指定——手動填的值可能跟實際網路狀態對不上，
白名單比對就會失準。偵測時排除 loopback 與 `169.254.*`（那是網路沒接通時系統
自己給的暫時位址），多張網卡時挑路由優先度最高的那張。

> **前提：IP 真的要是固定的。** 在路由器上做 DHCP 保留，或在每台設定靜態 IP 都可以。
> 如果 IP 會隨機變動，同一個人換到新 IP 就會被當成另一個人。

同一台電腦若有不同 Windows 使用者各自跑 Claude Code，兩者的 IP 相同，
會寫進同一個檔、後寫的覆蓋先寫的——這是刻意的：**用量以 IP 為單位計算，
不細分到個別使用者**。

### 名字怎麼設定

共享資料夾的**根目錄**放一份 `names.json`，記錄「IP → 名稱」的對照。
完整路徑就是共享路徑後面接檔名，例如：

```
T:\claude_usage\names.json          ← 對照表（同時是白名單）
T:\claude_usage\192.168.1.10.json         ← 各台自動產生，不用管
T:\claude_usage\192.168.1.20.json
```

檔名與位置都是固定的，程式只認這一個。內容長這樣：

```json
{
  "192.168.1.20": "小明",
  "192.168.1.31": "小華"
}
```

第一次使用時這個檔不存在，自己用記事本建一個即可（存檔類型選「所有檔案」，
檔名打 `names.json`，不要變成 `names.json.txt`）。
UTF-8 或 ANSI 存檔都可以，程式會自動判斷，中文名稱不會變亂碼。

**這份對照表同時也是白名單。** IP 沒登記在裡面的機器，
不會把自己的用量寫進共享資料夾——它仍然看得到別人的數字，但自己不列入統計。
這樣可以避免未經同意的機器混進來影響分配。

**名稱只有這一個來源。** 各台不能自己設定顯示名稱，全部由這份對照表決定。

新增一台電腦或要改名字，都是**直接到共享資料夾用記事本編輯 `names.json`**。
小工具本身沒有提供編輯這份檔案的功能——因為它同時是白名單，
若每台都能從選單改，任何人都能把自己加進去，白名單就管不住了。
要限制誰能改，就在共享資料夾對這個檔案設 NTFS 權限。

順帶一個好處：把多個 IP 對到**同一個名稱**（同一個人的幾台、
或同一個部門、同一種用途都可以），
「依名稱」檢視就會自動把那幾台加在一起。

因為對照表放在共享資料夾，**改一次所有人都看得到**，不必跑遍每台電腦。
還沒登記的機器，畫面上會用紅字提示自己的 IP，方便報給管理者登記。

### 三種檢視方式

右鍵 →「檢視方式」可以切換：

| 模式 | 一列代表 | 副標顯示 | 適合 |
| --- | --- | --- | --- |
| **依固定 IP**（預設） | 一個 IP | IP 與 token 數 | 用 IP 管理的環境 |
| **依名稱** | 一個名稱（多個 IP 自動加總） | 有哪幾個 IP | 想用人／部門／用途分組時 |

### 電腦數量怎麼控制

**架構上沒有數量限制。** 程式讀共享資料夾裡的所有回報檔，有幾個就顯示幾列。

| 動作 | 做法 |
| --- | --- |
| **加入一台** | 複製資料夾 → 改好 `$script:SharedFolder` → 執行 `Install.ps1` → **請管理者把它的 IP 加進 `names.json`** |
| **暫時移除** | 把那台的 IP 從 `names.json` 拿掉，它就不再上傳 |
| **永久移除** | 先把 IP 從 `names.json` 拿掉，再刪掉共享資料夾裡它的 JSON 檔 |

> **順序很重要：先從 `names.json` 拿掉 IP，再刪 JSON 檔。**
> 只刪檔案是沒用的——那台只要還在白名單裡而且小工具還在跑，
> 下次更新又會把自己寫回來。

真正的限制是**視窗高度**：每台約佔 50px，10 台左右還放得下，20 台就會超出螢幕。
所以有兩個顯示控制：

| 規則 | 值 |
| --- | --- |
| 最多列出幾台 | **5 台**。超過的合併成一列「其他 N 台」，本機那列一定保留 |
| 久未回報就不顯示 | **超過 30 天**。只是不列出來，紀錄還在共享資料夾裡 |

這兩個是固定值，不做成選項——畫面高度有限，列太多會超出螢幕；
太久沒回報的機器留著也只是干擾判讀。

被合併進「其他 N 台」的用量**仍然計入總數**，所以各列百分比加起來還是等於帳號總用量。

## 共享資料夾路徑

路徑是**寫死在程式裡**的，不從選單設定 —— 這樣每台不會各設各的，也不會有人不小心指到別的地方。
部署到新環境時改 `ClaudeUsageWidget.ps1` 開頭這一行就好：

```powershell
$script:SharedFolder = 'T:\claude_usage'
```

**連不上的時候不會出錯。** 筆電帶出公司、NAS 沒開機、路徑打錯，
小工具都會自動改成只顯示這台自己的用量（本 5 小時與本週的 token 數），
並用灰字註明「未連上共享資料夾」。回到網路上就自動恢復。

> 為了不讓視窗卡住，程式會先用 1.2 秒逾時的連線測試確認主機在不在。
> 直接對連不上的網路路徑做檔案檢查會等到系統自己逾時 —— 實測要 8 秒，
> 那段時間整個視窗是凍住的。

## 運作原理

### 帳號額度從哪來

小工具讀取 `%USERPROFILE%\.claude\.credentials.json` 裡的 OAuth 存取權杖，
向 `https://api.anthropic.com/api/oauth/usage` 查詢額度狀態。
這跟你在 Claude Code 裡輸入 `/usage` 是同一個來源。

**這個查詢不會消耗 token 額度。** 它讀的是帳號狀態，不是把訊息送給模型運算，
就像去 ATM 查餘額不會扣錢一樣。

權杖只會送到 Anthropic 官方伺服器，不會傳給任何第三方，也不會寫進 log 檔。

### 為什麼需要各台自己算

**額度是綁帳號的，不是綁機器的。** 多台電腦登入同一個 Claude 帳號時，
每台打 API 拿到的百分比完全一樣，那個 API 沒有任何「哪台用的」資訊。

所以小工具把兩份資料合起來判斷：

1. **帳號總額度** —— 來自 API，官方精確數字
2. **各台的本機用量** —— 每台自己解析 `~/.claude/projects/**/*.jsonl`，
   算出自己在同一個時間視窗內產生的用量

各台把第 2 項寫進共用資料夾，彼此就都看得到全貌。時間視窗是從 API 給的重置時間往回推，
所以每台切出來的區間界線完全一致，加總才有意義。

共享資料夾裡每個「IP + Windows 使用者」組合會產生一個 JSON（約 280 bytes），
**內容只有 IP 與彙總後的數字**——IP、金額當量、token 數、更新時間，
不含任何對話內容、檔案路徑或提示詞。

### 用量怎麼換算

不同模型的單位成本差很多（Opus 的 output 是 Haiku 的 5 倍價），
直接比 token 數會讓跑輕量模型的機器被高估。所以先用官方定價把各種 token
換算成 USD 當量，再拿來比較：

| 項目 | 計價方式 |
| --- | --- |
| input | 該模型的 input 單價 |
| output | 該模型的 output 單價 |
| cache read | input 單價 × 0.1 |
| cache write（5 分鐘 TTL） | input 單價 × 1.25 |
| cache write（1 小時 TTL） | input 單價 × 2 |

> **cache read / cache write 是什麼**：Claude 會把重複的上下文存成快取，
> 讀快取只要 1/10 價，寫快取要 2 倍價。實際用量裡 cache read 往往佔絕大多數
> （實測某個 session 是 6.6 億 vs input 的 4758），倍率用錯結果會完全失真。

換算過程還有兩個修正，少了任何一個數字都會錯：

1. **以 `requestId` 去重** —— 同一次 API 請求會被寫進紀錄好幾次
   （實測 48 行只對應 21 次真實請求），直接累加會高估一倍以上
2. **用 `cost-state` 校正總量** —— 有些背景請求（分類、標題生成之類）不會寫成對話訊息，
   但一樣計入額度，只有 Claude Code 自己寫的 `cost-state` 算得到，實測差距約 5%

校正後與 Claude Code 自己記的 `totalCostUSD` **完全吻合（差異 0.0000%）**。

> 訂閱制用戶不會真的被收這些錢。USD 當量只是拿來當跨模型比較的共同尺度。

### 效能

解析結果會依「檔案大小 + 最後修改時間」快取，只有正在使用中的 session 檔需要重新解析。
實測首次約 3.1 秒，之後降到 30 毫秒以內。快取存在 `local-usage-cache.json`。

### 這個估算的極限

Anthropic **沒有公開**額度百分比的實際計算權重，這裡是用公開定價當代理指標。
所以「各台佔用」的**相對大小可信**（誰是大戶一目瞭然），
但絕對數字僅供參考，不是官方值。**上方的帳號總額度才是精確的。**

## 疑難排解

**小工具沒出現**

先看 `widget.log` 最後幾行。若完全沒有 log，多半是 PowerShell 執行原則擋住了；
`StartWidget.vbs` 已經帶了 `-ExecutionPolicy Bypass`，正常情況不會遇到。

**顯示「存取權杖已失效」**

權杖過期了。開啟一次 Claude Code，它會自動更新 `.credentials.json`，
小工具在下次排程更新時就會恢復。換 Claude 帳號也是一樣，不必重裝或重啟。

**顯示「無法連線」**

網路問題或 API 暫時無回應，下一次排程會自動重試，不需手動處理。

**顯示「共享資料夾無法寫入」**

確認那個網路路徑存在、而且這台電腦有寫入權限。筆電帶出公司時會連不到區網共享資料夾，
這時只會看到自己的數字，接回網路就恢復。

**視窗跑到螢幕外**

刪掉 `config.json` 再重新啟動，位置會重設回右上角。

**開了好幾個視窗**

不會發生。程式有單一實例保護，重複點捷徑只會有一個視窗。

**某台一直顯示離線**

那台的小工具沒在跑，或它的共享資料夾設定不同。到那台上確認一次。

## 移除

```powershell
# 移除桌面捷徑與開機啟動（程式檔保留）
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\ClaudeUsageWidget\Install.ps1" -Uninstall
```

完全移除就直接刪掉整個 `ClaudeUsageWidget` 資料夾。
如果有設共享，記得也把共享資料夾裡那台的 JSON 刪掉。

## 已知限制

- **API 端點沒有官方公開文件**，若 Anthropic 改版可能失效。真的失效時小工具會顯示
  錯誤訊息而不會當掉，屆時需要調整 `ClaudeUsageWidget.ps1` 裡 `Get-UsageData` 的網址或標頭。
- **舊的對話紀錄檔沒有 `cost-state`**，那種檔案只能用純解析值，誤差約 5%。
  新產生的紀錄都有，不受影響。
- **進度條顏色**為藍（低）→ 琥珀（50% 起）→ 紅（75% 起）。
  顏色只是輔助，百分比數字本身才是主要資訊，不依賴辨色能力也能判讀。
- **設定不會跨電腦同步**，每台各自設定（共享的只有用量數字與名稱對照表）。
