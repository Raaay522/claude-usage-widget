# Claude Code 用量桌面小工具

把 Claude Code `/usage` 的額度做成常駐桌面的小視窗，
多台電腦共用同一個帳號時，還看得出**是誰用掉了額度**。

```
┌────────────────────────────────┐
│ ● Claude Code 用量          ✕  │
│                                │
│ 5 小時區間                 23% │   ← 帳號額度（官方數字）
│ ██████░░░░░░░░░░░░░░░░░░░░░░░  │
│ 16:39 重置 · 剩 3 小時 21 分   │
│                                │
│ 每週額度                   13% │
│ ███░░░░░░░░░░░░░░░░░░░░░░░░░░  │
│                                │
│ ── 本 5 小時各名稱佔用（估算）─│
│ Alice（你）               15.7%│   ← 各人分攤（估算）
│ ████████████████████░░░░░░░░░  │
│ 192.168.1.10 · 108.6M tokens   │
│                                │
│ 小明                       5.2%│
│ ███████░░░░░░░░░░░░░░░░░░░░░░  │
│ 192.168.1.20 · 36.0M tokens    │
│                                │
│ 本機本週 246M · 更新 13:50   ↻ │
└────────────────────────────────┘
```

需求：Windows、PowerShell 5.1（系統內建）、已登入的 Claude Code。不必安裝額外軟體。

---

## 安裝

### 只用一台

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\ClaudeUsageWidget\Install.ps1"
```

建立桌面捷徑與開機自動啟動，跑完小工具就會出現在螢幕右上角，可直接拖到想要的位置。

### 多台一起用

前兩步每台都要做，第三步整組做一次就好：

1. 把整個 `ClaudeUsageWidget` 資料夾複製過去，執行上面那行 `Install.ps1`
2. 確認這台的 `T:` 對應到跟其他台**同一個**網路位置
   （程式預設用 `T:\claude_usage`；要改路徑就編輯 `ClaudeUsageWidget.ps1` 開頭的
   `$script:SharedFolder`）
3. 在共享資料夾建一份 `names.json`，把每台的 IP 與名稱填進去：

   ```json
   {
     "192.168.1.10": "Alice",
     "192.168.1.20": "小明"
   }
   ```

**第 3 步是必要的。** `names.json` 同時是白名單，**沒登記的機器不會上傳用量**。
小工具在未登記時會用紅字顯示自己的 IP，把那個 IP 填進去即可。

> 多個 IP 對到**同一個名稱**時，那幾台的用量會自動合併成一列。
> 所以要以人、部門還是機器為單位看，由 `names.json` 怎麼寫決定。

## 操作

小工具上按**右鍵**是主選單。

| 動作 | 做法 |
| --- | --- |
| 移動位置 | 左鍵拖曳，放開自動記住 |
| 立即更新 | 點右下角的環狀箭頭 |
| 收到狀態列 | 點右上角 ✕；左鍵點狀態列圖示可叫回來 |
| 真正結束 | 右鍵 →「結束」 |
| 其他 | 右鍵可調主題、更新間隔、透明度、統計區間（本 5 小時／本週／兩者） |

狀態列圖示本身就是環形進度，不用點開就看得到目前用量。

## 說明

- **上半段的帳號額度是官方精確數字**，跟 `/usage` 同一個來源。查詢不會消耗 token。
- **下半段的各人佔用是估算**：Anthropic 沒有公開額度的計算權重，這裡是用各台的本機
  用量按比例分攤。相對大小可信，絕對數字僅供參考。
- 連不上共享資料夾時（筆電帶出門、伺服器沒開），會自動只顯示本機用量，不會出錯。
- 程式檔請保持 **UTF-8 with BOM**，否則 PowerShell 5.1 會把中文讀成亂碼。

## 移除

```powershell
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\ClaudeUsageWidget\Install.ps1" -Uninstall
```

移除捷徑與開機啟動；程式檔要刪就直接刪掉整個資料夾。
